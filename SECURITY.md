# Security Policy

Game Spelunker runs inside the Unity Editor, downloads AssetRipper from its official GitHub release and starts it
locally, bound to `127.0.0.1` on a random port.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private
[security advisory form](https://github.com/Nekuzaky/game-spelunker/security/advisories/new) instead, with steps to
reproduce. You should get an answer within a few days.

Issues in AssetRipper itself should be reported to the [AssetRipper project](https://github.com/AssetRipper/AssetRipper).

## Supported versions

Only the latest release receives fixes.
