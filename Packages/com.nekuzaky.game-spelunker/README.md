# Game Spelunker

Editor window to see how Unity games are built and to prepare mods for games that allow them.

Open it with **Tools → Game Spelunker** (`Ctrl+Shift+G`).

- **Build report** of any installed Unity game, and one-click install of the game's own Unity version.
- **Extraction** with AssetRipper (downloaded on first use) into a project that is ready to open: the game's code is
  made to compile, materials and shaders are repaired, everything is imported in the background and checked in Play
  mode.
- **Explore** the result: health dashboard, scenes, textures, plugins, code fixes and decompiled scripts, or import
  the assets into the project you have open.

Full documentation: https://nekuzaky.com/docs/unity-game-spelunker

> Only extract games you own. Extracted assets and code still belong to their authors: use them to learn or to
> build mods the developer allows, never redistribute them, and respect each game's license (EULA).
